# Security policy

Do not report a secret, customer record, access token, cookie, private URL, or production log in a public issue.

For a suspected vulnerability, use a private GitHub security advisory for this repository when that feature is enabled. If private reporting is not available, contact the repository owner through a private channel before opening an issue. Include a short impact summary, affected release, reproduction steps that use synthetic data, and a safe contact path.

The public repository contains deployment guidance only. Do not assume that an example configuration is safe for production. Replace every placeholder and keep secrets in a secret manager or an operator-controlled environment file.
